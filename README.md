# Capstone-2024

This repository contains various components for the 2024 Capstone project.

## Project Components

### 1. Ground Station GUI (Cube Orange)
Python-based GUI for monitoring drone/vehicle telemetry data including battery voltage, GPS, attitude, and system status using DroneKit.

### 2. Light Detection and Throughput Monitoring
Raspberry Pi application using PiCamera2 and OpenCV for detecting light throughput with real-time status GUI.

### 3. Arduino Pump Control
Complete guide and code for controlling a 4-wire brushless DC pump (24VDC) using Arduino with PWM control.
